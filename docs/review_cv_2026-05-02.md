### 🔴 CRITICAL — Issue #1: harris.py Is a 1-Line Empty Stub
**Location:** cv/harris.py (entire file)
**Dimension:** Correctness / AI-ML

**Problem:**
The file contains a single empty line. FR-CV-02 requires Harris Corner
Detector implementation with keypoint visualization AND threshold tuning
analysis. This requirement is listed as "✅ Satisfied" in
requirements_validation.md, but there is zero code. The CV course marks
specifically list Harris detection as a graded deliverable (row 4.2 and 4.3).

**Example of the problem:**
```python
# harris.py — entire file content:

```

**Best Fix:**
Implement Harris corner detection using cv2.cornerHarris, then convert
response to keypoints and draw them. Add a threshold sweep loop (e.g.
thresholds = [0.01, 0.05, 0.1, 0.2]) to document the visual and numeric
effect. Include visualization saving with cv2.imwrite.

```python
import cv2
import numpy as np

def detect_harris(img, threshold=0.01):
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY).astype(np.float32)
    response = cv2.cornerHarris(gray, blockSize=2, ksize=3, k=0.04)
    response_norm = cv2.normalize(response, None, 0, 1, cv2.NORM_MINMAX)
    keypoints = np.argwhere(response_norm > threshold)
    return response_norm, keypoints

def threshold_analysis(img, thresholds=(0.01, 0.05, 0.10, 0.20)):
    results = {}
    for t in thresholds:
        _, kp = detect_harris(img, threshold=t)
        results[t] = {"keypoint_count": len(kp)}
    return results
```

**Best Fix:**
Implement BFMatcher (or FLANN) with ratio test, then compute match quality
as the ratio of good matches to total candidate matches. Use
cv2.drawMatches for visualization.

```python
import cv2

def match_sift(des1, des2, ratio=0.75):
    bf = cv2.BFMatcher(cv2.NORM_L2, crossCheck=False)
    raw = bf.knnMatch(des1, des2, k=2)
    good = [m for m, n in raw if m.distance < ratio * n.distance]
    accuracy = len(good) / len(raw) if raw else 0.0
    return good, accuracy

def draw_matches(img1, kp1, img2, kp2, matches, out_path):
    vis = cv2.drawMatches(img1, kp1, img2, kp2, matches[:20], None,
                          flags=cv2.DrawMatchesFlags_NOT_DRAW_SINGLE_POINTS)
    cv2.imwrite(out_path, vis)
```

**Best Fix:**

(PSNR or SSIM delta) so the comparison is quantitative, satisfying FR-CV-01.

```python
import cv2
import numpy as np

def preprocess_gaussian(img, ksize=(5, 5)):
    resized = cv2.resize(img, (224, 224))
    return cv2.GaussianBlur(resized, ksize, 0)

def preprocess_median(img, ksize=5):
    resized = cv2.resize(img, (224, 224))
    return cv2.medianBlur(resized, ksize)

def compare_filters(img):
    gauss = preprocess_gaussian(img)
    median = preprocess_median(img)
    psnr_g = cv2.PSNR(img, cv2.resize(gauss, img.shape[1::-1]))
    psnr_m = cv2.PSNR(img, cv2.resize(median, img.shape[1::-1]))
    return gauss, median, {"psnr_gaussian": psnr_g, "psnr_median": psnr_m}
```

### 🟠 HIGH — Issue #5: evaluation.py Missing IoU Metric
**Location:** cv/evaluation.py:3–6
**Dimension:** AI-ML / Correctness (FR-CV-07)

**Problem:**
FR-CV-07 explicitly requires "IoU (Intersection over Union) for the
segmentation step." The evaluate() function only calls accuracy_score and
classification_report — it has no IoU computation whatsoever. This metric
is a mandatory deliverable for the CV course evaluation.

**Example of the problem:**
```python
def evaluate(y_true, y_pred):
    acc = accuracy_score(y_true, y_pred)
    report = classification_report(y_true, y_pred)
    return acc, report
    # No IoU, no matching_accuracy parameter
```

**Best Fix:**
Add an IoU helper that compares segmentation masks against ground-truth masks.
GTSRB provides bounding-box annotations — convert to binary mask and compute
pixel-level IoU.

```python
import numpy as np

def compute_iou(pred_mask: np.ndarray, gt_mask: np.ndarray) -> float:
    intersection = np.logical_and(pred_mask, gt_mask).sum()
    union = np.logical_or(pred_mask, gt_mask).sum()
    return float(intersection) / (float(union) + 1e-8)

def evaluate(y_true, y_pred, seg_ious=None, matching_accuracies=None):
    acc = accuracy_score(y_true, y_pred)
    report = classification_report(y_true, y_pred)
    mean_iou = float(np.mean(seg_ious)) if seg_ious else None
    mean_match = float(np.mean(matching_accuracies)) if matching_accuracies else None
    return {"accuracy": acc, "report": report,
            "mean_iou": mean_iou, "mean_matching_accuracy": mean_match}
```

```python
def build_gaussian_pyramid(img, levels=3):
```

### 🟠 HIGH — Issue #10: segmentation.py Hardcodes k=2 With No IoU
**Location:** cv/segmentation.py:6
**Dimension:** AI-ML / Correctness (FR-CV-07)

**Problem:**
K-means is run with exactly 2 clusters, which splits the image into two
regions but does not necessarily isolate the sign region. More importantly,
the function returns the segmented image with no ground-truth mask comparison
and no IoU computation. FR-CV-07 requires the IoU metric for the
segmentation step. This function alone cannot satisfy that requirement.

**Example of the problem:**
```python
_, labels, centers = cv2.kmeans(
    Z, 2, None, ...           # k=2 hardcoded; no IoU returned
```

**Best Fix:**
Accept a ground-truth bounding box or mask argument, threshold to isolate the
dominant foreground cluster, and return both the segmented image and IoU.

```python
def segment(img, gt_mask=None, k=3):
    Z = img.reshape((-1, 3)).astype(np.float32)
    _, labels, centers = cv2.kmeans(
        Z, k, None,
        (cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 10, 1.0),
        10, cv2.KMEANS_RANDOM_CENTERS
    )
    centers = np.uint8(centers)
    segmented = centers[labels.flatten()].reshape(img.shape)
    iou = None
    if gt_mask is not None:
        pred_mask = (labels.reshape(img.shape[:2]) == 0)
        iou = compute_iou(pred_mask, gt_mask)
    return segmented, iou
```

**Location:** cv/sift.py:3
**Dimension:** Maintainability / Correctness

**Problem:**

mutable object in module global scope. This makes unit testing harder,
prevents parameter customization (nfeatures, nOctaveLayers), and causes

**Example of the problem:**
```python
sift = cv2.SIFT_create()      # executed at import; not configurable

def extract_sift(img):
    ...
    kp, des = sift.detectAndCompute(gray, None)
```

**Best Fix:**
```python
def extract_sift(img, nfeatures=0, nOctaveLayers=3):
    detector = cv2.SIFT_create(nfeatures=nfeatures, nOctaveLayers=nOctaveLayers)
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

```
